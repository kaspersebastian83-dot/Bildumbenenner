FotoKit: PDF-Bilddokumentation

Scope
Only the PDF writer/layout block in index.html changes. Every application byte
outside that block is checked against main b616164f5ab24faa5371f4eb714276f6080a8bf3.
The temporary F3/F6/N2 composition checks the same invariant against its own
security baseline. Storage, recovery, project identity, renaming, original image
handling, CSV, ZIP and PDF save/overwrite checks remain outside the changed block.

Design
A4, restrained blue, compact repeating header, original company symbol, separate
photo-number badges and captions, consistent footer and page totals. All previous
project fields remain on a flowing cover/index. Portrait/landscape photos use
contain scaling, never cropping. Two photos per page remains the normal maximum;
long captions can require one photo per page or caption continuation pages.
The sampling table repeats its column headings on continuation pages.

Palette follows SpesenKit lib/pdf-statement.ts: navy 33/48/62, blue 53/109/168,
muted 98/120/143. Company name: Dr. Schiffers & Partner.
tools/embed-pdf-logo.py embeds lossless RGB and alpha streams, preserving the
original aspect ratio. Runtime PDF export requires no additional file request,
library or network access. The PNG is retained as a verifiable source resource.
One shared logo image/soft mask per PDF; header width 36 pt, watermark width
258 pt, opacity 0.035. The watermark is painted behind all body content and photos.
Combined compressed image/alpha streams occupy 40020 bytes per file, independent
of page count. Branding and readable text add bounded overhead; PDFs are not
claimed to have identical total sizes to main.
Since 1.23.0 each photo is encoded for its frame on the page (frame size x
chosen dpi: 150/220/300, JPEG 70/75/80 %), independent of the ZIP settings,
never upscaled; JPEG bytes therefore differ from main (smaller).

Limits
Existing Helvetica/WinAnsi character support is retained, including German
umlauts and Euro. Existing unsupported-script fallback is not redesigned here.
Native directory API tests retain their existing WebKit skips; the new PDF tests
run in both engines without those skips. Synthetic browser tests and PDF rendering
do not establish Windows/SMB/RDP or power-loss durability.

caption space use the same values. Full filenames and continuation pages remain.
